RGH — CF-Anchored Residual Gated Hybrid

Kiến trúc deep hybrid đề xuất cho bài toán khuyến nghị Amazon Books / Electronics (implicit feedback, rating ≥ 4, min ≥ 3 tương tác, cùng artifact với ALS/BPR/LightGCN/SBERT).

Tổng quan 2 tầng

① Candidate Retrieval
Union của 4 nguồn:
ALS (top 60) + LightGCN (top 60)
+ BLaIR / SBERT (top 60, metadata-only)
+ Popularity (top 15)
→ U ≈ 120–250 candidates / user
② Feature Builder
Per-user z-score trên U:
z_cf · z_gcn · z_txt
+ popularity, history_len, domain
Chuẩn hoá cùng thang đo trước fusion
③ Residual Reranker
score = wide + gate · Δ
Δ = DCN-V2 cross + Deep MLP
Gate b khởi tạo < 0 → an toàn cho CF
→ Listwise / hard-negative training
↓
score(u, i) = a_cf·z_cf + a_gcn·z_gcn + a_txt·z_txt + σ(w·h + b₀) · [cross_layers(x) + deep(x)]

Safety guarantee: nếu g → 0 thì score quy về tổng trọng số nhánh đã normalised — mô hình không phá hỏng ordering CF; nếu content/graph không ích, gate học được gate ≈ 0.

Training

L_rank = −log exp(s_pos/T) / Σ_{j∈U} exp(s_j/T) L_pair = −log σ(s_pos − s_neg_hard) (λ_pair ≈ 0.1) L = L_rank + λ_pair · L_pair
  • Negative = hard negatives từ retrieval (top non-positive) + random (ratio 1/10)
  • Optimizer: AdamW, lr 1e-3→1e-4, weight_decay 1e-4, grad clip 1.0
  • Early stop theo NDCG@10(validation) — test chỉ dùng 1 lần
  • Warmup 1 epoch; tối đa 10–20 epochs; checkpoint = top-1 validation

Protocol đánh giá

Retrieval
  • Retrieval Recall@120(U)
  • Coverage / novelty / popularity decile
  • Items ngoài catalog (cold): ~6.13% cần ghi rõ
Ranking
  • HR@5/10/20 · NDCG@5/10/20 · MRR · Precision · Recall · AP
  • Bootstrap 95% CI theo user (paired)
  • Tách warm/cold item; tách domain Books / Electronics
Acceptance checklist
  1. a_gcn = a_txt = gate = 0 ⇒ ≈ ALS (sanity check)
  2. + normalized branch scores ⇒ cải thiện
  3. + listwise loss ⇒ cải thiện tiếp
  4. + content (metadata-only) ⇒ mục tiêu vượt ALS → ensemble
  5. + graph branch ⇒ tối ưu cuối
Baseline hiện tại (cần beat): ALS 0.6845 HR@10 / 0.4882 NDCG@10 · BPR 0.6539 / 0.4517 · Deep Early Fusion 0.5700 / 0.3603 · Light Gated 0.5284 / 0.3037 · Ensemble ALS+BPR 0.7242 / 0.5603. RGH phải ≥ ALS; mục tiêu ≥ Ensemble.
